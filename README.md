# Deviprasad Shetty — Professional Portfolio

A minimalist, typography-driven personal portfolio website designed to showcase my academic journey, core technical skills, software engineering projects, and certifications. 

Built with a modern aesthetic featuring smooth scroll-reveal animations, responsive layouts, and clean CSS architecture.

## 🌐 Live Preview
> **Live Demo:** (https://github.com/dprasadshetty/Developer-portfolio)
---

## 🚀 Key Features

- **Interactive UI/UX:** Powered by a lightweight JavaScript `IntersectionObserver` to trigger smooth slide-up reveal animations as elements enter the viewport.
- **Responsive Grid Design:** Perfectly optimized for all devices, including desktops, tablets, and smartphones.
- **Thoughtful Typography & Theme:** Uses a bespoke cream-and-ink minimal palette with `Playfair Display` (serif) and `DM Sans` (sans-serif) typefaces.
- **No Heavy Frameworks:** Pure HTML, CSS, and vanilla JavaScript for lightning-fast load times.
